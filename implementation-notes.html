Tall Talents Package Migration Implementation Notes

This file is the running implementation log for the package-format and self-iteration migration.

Decisions Carried From The Design Session

  • Active talents move from single markdown files to package folders.
  • The package entrypoint is TALENT.md.
  • Every package requires CHANGELOG.md.
  • Self-iteration may edit active talents automatically when concrete conversation evidence exists.
  • Each automatic change must append a package-local changelog entry with session, change, evidence, effect, and oscillation check.
  • Self-iteration writes tiny report cards for non-trivial conversations, including no-change decisions.
  • Raw reports are local-only under private/self-iteration/; sanitized reports may be committed under reports/self-iteration/.
  • Self-iteration may refine, create, archive, or split talents; automatic merge is out of scope.
