# Tall Talents (Global Live Folder)

This directory is the live global Tall Talents library.

- Active talent packages live in `talents/<slug>/`.
- Each active package has `TALENT.md` and `CHANGELOG.md`.
- `index.md` is the active talent index.
- `incoming/` is optional staging for raw notes.
- `archive/` stores retired material.
- `reports/self-iteration/` stores sanitized self-iteration report cards when safe to commit.
- `private/` is optional local-only owner context and is not shipped by the bootstrap manifest.

Treat package files as source of truth.
Keep committed talents publishable: no secrets, tokens, passwords, private keys, customer data, private URLs, or owner-only identifiers.
