# Use Tall Talents In This Task

1. If the user explicitly invoked a non-Tall-Talents Codex skill, plugin, or slash-style workflow, treat that invoked workflow as controlling.
2. Use Tall Talents alongside that external workflow only if the user also asked for Tall Talents, the invoked workflow requests it, the task has a separate uncovered stage, or the task is about Tall Talents itself.
3. Read `~/.tall-talents/index.md`.
4. Select only relevant active talent(s).
5. Name which talent(s) are being used.
6. For multiple talents, state the primary talent, supporting talents, and execution order.
7. Apply their procedures literally unless task context requires adaptation.
8. If none fit, explicitly state no talent is being force-fit.
